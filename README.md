# Hatoms portfolio

Premium dark placeholder portfolio built with React, TypeScript, Vite, Tailwind CSS, Framer Motion and Lenis.

## Run locally

Node.js 20 LTS or newer is required.

```bash
npm install
npm run dev
```

For a production build:

```bash
npm run build
npm run preview
```

## Structure

- `src/components/layout` — navigation and ambient background
- `src/components/sections` — reusable landing sections
- `src/components/ui` — shared UI primitives
- `src/constants/content.ts` — all placeholder content
- `src/lib` — utilities

Replace the entries in `src/constants/content.ts` to add real projects, events, technologies and links without touching the visual components.
